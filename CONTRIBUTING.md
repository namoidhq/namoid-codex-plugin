# Contributing

Thank you for helping improve NamoID's Codex integration.

1. Open an issue for material behavior or permission changes.
2. Keep this repository a thin adapter to the hosted Setup Assistant MCP.
3. Do not add credentials, tokens, customer data, or duplicated backend logic.
4. Preserve least-privilege OAuth scopes and require explicit approval before
   configuration writes.
5. Run the repository validation workflow before submitting a pull request.

By contributing, you agree that your contribution is licensed under Apache-2.0.
